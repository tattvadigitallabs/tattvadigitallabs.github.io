# Tattva Digital Labs website

Live at https://tattvadigitallabs.github.io (GitHub Pages, `main` branch).

| Page | Path |
|---|---|
| Company home: featured newest app + filterable app directory | `/` |
| All apps, grouped by category | `/apps/` |
| One page per app | `/pdf-tools/`, `/image-compressor/`, `/finance-calculator/` |
| Privacy (company + one section per app) | `/privacy/` (`#<app-slug>`) |
| Support (app chooser + FAQ per app) | `/support/` (`#<app-slug>`) |

## How it's built
All pages are generated by `scripts/build_site.py` from one **app registry**:

```
scripts/apps.py          CATEGORIES and APPS: name, category, status, card text, FAQ, product page content
scripts/build_site.py    page templates: home, /apps/, product page, privacy, support
scripts/site_lib.py      shared header, footer, helpers (bump ASSET_VERSION when CSS/JS change)
scripts/legacy_pages.py  the original hand-crafted pages for Image Compressor and Finance Calculator
content/privacy/         privacy text per app (<slug>.html) plus company intro/outro
assets/apps.css          directory: filter chips, search, app cards, category sections
```

```bash
python3 scripts/build_site.py .
```

## Adding an app
1. Icon → `assets/brand/<slug>-icon.svg`; screenshots (450×1000 JPG) → `assets/img/`.
2. Add an entry to `APPS` in `scripts/apps.py` (use an existing category or add one to `CATEGORIES`).
   Give it a `page` dict to use the generic product page template (see Tattva PDF Tools).
3. Add its privacy text to `content/privacy/<slug>.html`.
4. Build. The app then appears on the home directory, `/apps/`, its own page, the privacy page and the support page.
5. When it's on Google Play, set `"status": "live"` and `"play_url"` to switch the badges and store buttons.
